# Secure Federated Learning Demo

A reproducible educational implementation of federated learning with explicit privacy/security controls.

## Roadmap implemented by this repository
- deterministic synthetic clients
- local model training
- FedAvg aggregation
- client update validation and clipping
- optional Gaussian differential privacy noise
- experiment metrics and reproducible seeds
- attack/defense demonstrations

This project is for research and education; privacy guarantees depend on the documented threat model and parameters.
